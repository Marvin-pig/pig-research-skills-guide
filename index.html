使用 Codex 或具备本地文件和终端能力的 agent。提供文件夹的本地路径，让它完成安装、环境配置和检查。

向提供方获取有使用权限的 9.2.0 完整 skill ZIP，Windows 与 macOS 使用同一份。本教程不提供数据库下载。

预留 ZIP、解压后的完整 skill、软件依赖和研究输出空间；如果 agent 另行复制到技能目录，还需要一份完整副本的空间。联合包已包含对应数据库，无需重复安装各单库包。

提供本地路径

让 agent 在你的电脑上读取

将文件夹路径粘贴到对话中，或通过 agent 的本地文件夹选择功能提供。无需把数据库上传为聊天附件。

3
发送下面一句话

配置后检查实际功能

agent 会读取包内说明，复用可用环境、补齐依赖，并检查取数、分析、绘图和文稿导出。完成后按提示重新打开会话并选择 skill。

请把这个 skill 安装到当前 agent，配置所需运行环境，并检查能否正常使用。
i
详细配置说明已经放在 skill 里。

你只需提供文件夹和上面的提示词。首次配置软件依赖通常需要联网；已经配置好的本地分析可以离线使用。软件安装窗口或必须本人操作的步骤，由 agent 说明。

已经装过、换电脑或使用其他 agent？

同样提供完整文件夹和这句提示词。已有可用环境优先复用；换电脑时在新系统上配置依赖。其他 agent 按自身规则发现 skill，并实际检查本地脚本执行和文件输出；仅能聊天的工具不能执行数据库分析。

包内“安装说明.md”面向使用者，“references/environment.md”供 agent 配置与核对。Codex 默认技能目录为当前用户的 .codex/skills，设置 CODEX_HOME 时使用其 skills 子目录。不要只复制 SKILL.md。

同一份源码与数据可跨系统交付；环境兼容性仍需在使用者电脑上检查。macOS 本机运行验证不能代替原生 Windows 或所有其他 agent 的验证。

完整流程

五段研究旅程，
发现问题可以回到前一步。

循环由实际证据推动：发现定义或时间窗口问题，就回到方案；模型诊断不充分，就补分析。只重做受影响的部分，保留阴性、不一致与无法估计的结果。

把文件夹提供给 agent 就可以了吗？+

提供本地文件夹路径，再发送上面的安装提示词。agent 需要放置完整 skill、配置依赖并实际检查功能；仅看到 skill 名称不代表环境已就绪。

Windows 和 Mac 需要不同的包吗？+

现在使用同一份完整 skill ZIP。Python、R 及其他依赖由 agent 在当前系统上配置；不要把 Mac 的二进制环境复制到 Windows。

我的电脑已经有 Python 和 R，还要重新安装吗？+

先检查并复用兼容环境，只补齐缺失或不兼容的依赖。已有软件不是错误，也不需要先卸载。

配置中断或依赖下载失败怎么办？+

直接让当前 agent 检查实际错误并继续配置。已就绪部分可以复用，不用重新下载数据库。完成后让它说明哪些功能已验证，哪些仍未就绪。

数据要依赖原始目录吗？可以离线研究吗？+

对应包已包含完整数据与必要字典，分析不依赖制作机器或原始数据目录。已配置的本地分析可以离线使用；软件依赖下载与近期文献检索需要联网。

组学、影像或所有 MIMIC 数据都能直接分析吗？+

以包内实际数据为准：三库包中的 MIMIC 包含 MIMIC-IV 3.1 hosp 和 ICU，不能据此推断包含影像、文本、波形或组学。需要其他模块时先提供并完成相应适配。

连续执行会直接做到论文吗？+

交付范围和推进方式分别确定。确认方案并明确要求做到全文后，助手完成该范围；只要求分析就停在分析。

可以直接回复“1”吗？+

可以，当前选项清楚时数字或自然语言都有效。通常 1 是推荐，最后是自定义。连续执行中的进度建议不会撤销已有委托。

使用其他 agent，需要额外适配吗？+

包内附有配置与验证说明，agent 按自己的技能目录和本地工具执行。不同产品的权限和工具能力不同，需由实际功能检查确认；不保证只有文本对话能力的工具也能完成研究。

安装和验证文件会混进投稿包吗？+

配置和验证记录保存在 skill 外，研究过程与复现记录留在工作区；投稿目录只保留需要提交的稿件、定稿图表、补充材料与相应附件。
