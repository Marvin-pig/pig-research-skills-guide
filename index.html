向提供方获取有使用权限的 9.2.0 系统专用完整 ZIP。本教程不提供数据库下载。

macOS mimic-eicu-inspire-pig-skill-macOS.zipWindows x64 mimic-eicu-inspire-pig-skill-Windows-x64.zip

空间按 ZIP + 解压副本 + 安装副本计算，另给软件依赖及研究输出留余量；建议在 ZIP 和解压目录之外，再预留至少一份解压体积加 10 GiB。多个 skill 共用软件环境，但各有完整数据副本。

Mac
APPLE SILICON / INTEL

macOS 安装

  1. 完整解压 -macOS.zip，保留 skill 文件夹与旁边的安装入口。
  2. 双击 Install.command。Python、R、科研及图册依赖由安装器准备；若出现官方 R 安装窗口，按窗口完成。
  3. 看到 Full installation COMPLETE，彻底退出并重开 Codex，选择 skill 开始使用。

新装 R 的官方安装包要求 Apple Silicon macOS 14+、Intel macOS 11+；Codex 自身的系统要求以官方说明为准。已有满足要求的环境会复用。

Win
WINDOWS x64

Windows 安装

  1. 右键 -Windows-x64.zip → 全部解压，建议使用 C:\PIGInstall 等短路径。
  2. 双击外层 Install.cmd。Python、R、科研及图册依赖由安装器准备。
  3. 看到 Full installation COMPLETE，彻底退出并重开 Codex，选择 skill 开始使用。

安装器面向 Windows 10/11 x64、PowerShell 5.1+；Codex 自身要求以官方说明为准。Windows ARM 尚未原生验证。不要复制 Mac 的 Python/R 环境到 Windows。

完成时会看到Full installation COMPLETE

本包登记的环境、数据、模型计算、图表和 Word 导出检查全部通过。账号登录和必要的系统安装窗口由你完成。

未完成时Full installation INCOMPLETE

结束后自动打开中文结果页，说明失败阶段和恢复办法。按提示处理后再次双击同一入口，检查通过的依赖会复用，不用逐个寻找日志。

✓
一次安装，按实际功能验证。

兼容的软件与检查通过的依赖会复用；缺失项逐步准备。以安装结果页为准，所有研究功能检查通过后再显示完成。

已装旧版、换电脑或只拖过 skill 文件夹？

用新版对应系统的完整 ZIP 运行同一安装入口，补齐环境并更新 skill。原研究项目放在独立工作区，继续研究前让助手读取已有方案与结果。只拖入文件夹、只运行底层 scripts/install.py，都不能作为完整首装已完成的依据。

Skill 默认位于当前用户的 .codex/skills；设置了 CODEX_HOME 时使用其 skills 子目录。软件设置与安装日志分别位于 macOS 的 ~/Library/Application Support/PIG 或 Windows 的 %LOCALAPPDATA%\PIG；最新主安装结果固定为其中的 安装结果.html，不自动上传。

ZIP 使用 ZIP64；存储磁盘须支持大于 4 GB 的文件。换电脑重新运行对应系统安装包，不复制旧机器的二进制环境。其他 Agent 的技能目录、工具接入与权限机制需要单独验证。

验证范围：macOS 已完成本机完整安装和代表包解压运行；Windows 包完成文件、编码、路径和载荷检查，原生 Windows 首装仍待真机验收。完整安装覆盖当前包已登记功能；联网检索和新增研究方法仍可能需要额外条件。

完整流程

五段研究旅程，
发现问题可以回到前一步。

循环由实际证据推动：发现定义或时间窗口问题，就回到方案；模型诊断不充分，就补分析。只重做受影响的部分，保留阴性、不一致与无法估计的结果。

遇到英文状态时，不用紧张。它们描述的是“这一步能不能继续”，不是对你研究能力的评价。

PASS

已经通过

有实际检查证据，可以继续下一步。

NEEDS_REVIEW

需要确认

目前有可用材料，但还需要人来判断。

BLOCKED

暂时卡住

缺少关键数据或条件，解决后才能继续。

NOT_APPLICABLE

这次不适用

不是失败，只是当前问题不需要这一项。

按实际产物判断进度

选题与证据 → 详细方案 → 数据与模型 → 图表与解释 → 全文与审查。发现问题时回到受影响步骤，不用为了阶段编号重做已经有效的工作。

topic seed

一句题目、假设或初步想法；还不是完整研究设计。

PECO / PICO

把人群、因素或干预、比较和结果说清楚。

estimand

真正想估计的目标量，包括人群、时间、比较和效应尺度。

predesign feasibility

设计前的汇总式数据可行性检查，不做建模。

Question–Evidence Graph

问题、估计量、模型、诊断、输出和 Results 之间的证据图。

Methods + Results

方法与结果分析包；当委托范围包括全文时，继续完成其他章节和投稿材料。

常见问题与恢复

从哪里继续，
这里说清楚。

先看实际安装状态与失败阶段，避免反复手工配置。

只有拖入文件夹，没有运行安装入口，算完成了吗？+

文件夹能被发现，不代表分析与图表环境已准备好。请用 9.2.0 系统专用 ZIP 的外层安装入口补齐；以 Full installation COMPLETE 为完成标志。

Mac 提示无法打开脚本，或 Windows 阻止运行？+

确认使用对应系统的包且已经完整解压。Mac 可在系统允许的情况下右键打开，或在终端用 sh 执行 Install.command。Windows 使用 Install.cmd，它仅为本次 PowerShell 进程设置执行策略；组织策略仍需按所在单位要求处理，不要求关闭系统安全保护。

提示 Python 已安装，却又显示引导失败？+

Python 3.12 is already installed 本身是正常提示，无需卸载 Python。如果错误写成 failed (exit )，退出码为空，这是旧安装器的结果读取问题。使用安装器 2026.09.27.5 或更新版本；已有完整包可用配套的小型安装器修复包更新并续装，无需重下数据库。新版先运行验证兼容的 Python，已有版本直接复用。

安装中断或长时间停在依赖准备怎么办？+

新安装器逐项检查 R 依赖，显示正在处理的包，临时下载错误会有限重试。结束后自动打开中文结果页，按提示处理并再次双击同一入口即可复核续装，不必重新下载数据库或手动寻找日志。已有 9.2.0 完整包的 Windows 用户可使用配套的小型安装器修复包，双击 Install-Repair.cmd 更新并续装。少数无法自动解决的兼容性或系统管控问题，结果页会提供可复制摘要。

数据要依赖原始目录吗？可以离线研究吗？+

对应包内已包含完整数据与必要字典，分析不依赖制作机器或原始数据目录。已配置的本地分析环境可以离线使用；首次安装软件、检索近期文献和其他网络工具需要联网。

组学、影像或“所有 MIMIC 数据”都能直接分析吗？+

以包内实际数据为准：三库包中的 MIMIC 数据包含 MIMIC-IV 3.1 hosp 和 ICU，不能据此推断有影像、文本、波形或组学。需要其他模块时先提供并完成相应适配。

连续执行会直接做到论文吗？+

交付范围和推进方式分别确定。你看过方案后明确要求做到全文，助手就完成该范围；只要求分析就停在分析。不会强制每次停在方法与结果，也不会把一句选题当作全流程授权。

可以直接回复“1”吗？+

可以，当前选项清楚时数字或自然语言都有效。通常 1 是推荐，最后是自定义。需要选择时等待真实回复；连续执行中的进度建议不会撤销已有委托。

为什么有字段仍不能直接做研究？+

还需核对编码、单位、测量时点、观察单位、可分析人数、事件和缺失。跨库先确定每个数据库的角色及可比性；独立数据库不自动合并患者，INSPIRE 手术层级也不等同于 ICU 层级。

使用其他 Agent 或换电脑怎么办？+

新电脑选择对应系统 ZIP 重新完整安装。当前完整安装器面向 Codex；其他 Agent 的技能发现、工具调用与文件输出需单独核对，不能只替换名称就认定兼容。

安装和验证文件会混进投稿包吗？+

不会作为投稿内容收进去。软件环境和安装日志在本机 PIG 配置目录，研究过程与复现记录放工作区；投稿目录只保留需要提交的稿件、定稿图表、补充材料与相应附件。

请检查这台电脑的 PIG 9.2.0 安装状态。先读取本机 PIG 配置目录中的 installation-latest.json、runtime.json 和 last_installation 报告，核对实际解释器、未完成阶段、科研依赖与模型及导出检查。给我具体原因和推荐恢复动作；普通修复在本次范围内完成，不重复同一失败，不上传私人数据。
